SEC 00 · 얻는 것

두 스테이지가 하나의 논증이다 — "지도를 만들 수 있고, 그 위를 산업 방식으로 달릴 수 있다"

T2는 두 단계다. 스테이지 A(SLAM 매핑)는 실제 AMR 설치 절차(현장 SLAM 1회 → 지도 고정)의 재현이고, 스테이지 B(자체 추종기)는 확정 아키텍처의 로봇 레벨 실행기 초판이다 — Nav2를 쓰지 않고 중앙이 준 경로를 추종만 하는 산업 AMR 방식. 이 가이드를 끝내면 아래를 스스로 할 수 있어야 한다.

#학습 목표관련 절
1TF 트리(map→odom→base_link→lidar_link)에서 각 변환을 누가 발행하는지 말할 수 있다SEC 01·02

3추종기의 제어 상태(정렬·순항·정지·재개)와 안전 필드 로직을 코드에서 짚을 수 있다SEC 03
4장애물을 투척해 정지·재개를 재현하고 엣지 CSV를 해석할 수 있다SEC 04·05
5"엣지 시간은 결정적, 분산은 정지 이벤트"가 DES 모델에 왜 중요한지 설명할 수 있다SEC 05

코드 위치: sil/t2_mapping/(스테이지 A) · sil/t2_follower/(스테이지 B)

SEC 01 · 선수 개념 5

이 다섯 개만 알면 두 스테이지가 전부 읽힌다

개념핵심T2에서 쓰인 곳
① 2D 라이다·LaserScan회전 거울이 한 평면을 훑어 각도별 거리 배열을 만든다. 배열엔 range_min(이보다 가까우면 안 보임 — 블라인드)과 range_max가 있고, 우리 설정은 1.0m / 25m. 스캔 평면 높이(~0.7m)보다 낮은 물체도 안 보인다안전 필드 정지 임계(1.2m)가 블라인드(1.0m) 위에 있어야 하는 이유 · 삽질 ⑤
② TF 트리좌표계들의 부모-자식 변환 트리. odom→base_link는 시뮬(오도메트리)이, base_link→lidar_link는 고정 변환이, map→odom은 SLAM이 발행한다 — SLAM의 출력이 "지도 좌표계에서 오도메트리 누적 오차를 보정하는 변환"이라는 뜻mapping_sim.py의 TF 발행 노드 2개 + slam_toolbox
③ SLAM·점유 격자스캔들을 이어 맞추며(스캔 매칭) 지도를 만들고 동시에 자기 위치를 추정한다. 산출물은 점유 격자(5cm 셀 — 점유/자유/미지). slam_toolbox online_async가 Humble 표준스테이지 A 전부 · 지도는 경로망 설계의 근거 자료
④ Pure Pursuit·P 제어목표점 방위각 오차 α에 비례(K·α)해 각속도를 내고, 오차가 크면 멈춰 서서 정렬부터 한다. 여기에 명령 램프(가속 제한 — T1 실측의 결론)를 걸어 실기 거동을 흉내낸다follower.py 제어 루프
⑤ 보호 필드산업 AMR의 안전 관행 — 진행 경로 위 영역에 물체가 들면 감속→정지, 벗어나면 재개. 모양이 중요하다: 원뿔(각도 섹터)이 아니라 로봇 폭 기반 사각 대역이어야 통로 옆 물체에 오탐하지 않는다cb_scan의 사각 필드 · 삽질 ③
한 가지 함정 지식회전 라이다의 스캔은 순간 사진이 아니라 1/10초 노출이다. 로봇이 π/4 rad/s로 도는 동안 찍힌 한 바퀴 스캔은 시작과 끝의 방향이 4.5° 다르다 — SLAM은 순간 스캔을 가정하므로 이 스미어가 그대로 지도 오차가 된다. 회전 속도를 절반(π/8)으로 낮춘 것만으로 지도 오차가 18cm → 3.4cm로 떨어졌다(SEC 05).

용어가 낯설면 용어사전 A(로보틱스)부터.

SEC 02 · 아키텍처

같은 시뮬, 갈아 끼우는 상대 — 스테이지 A는 SLAM, B는 추종기

추종기가 지도를 안 쓰는 게 맞나

질문답
왜 지도 없이 odom으로 추종하나확정 아키텍처에서 로봇은 중앙(FMS)이 준 노드 시퀀스를 따라갈 뿐이다. 시뮬의 odom은 드리프트가 없어(물리 pose 직독) 지도 정합 없이도 좌표가 유효하다. 실기의 위치추정(AMCL류) 검증은 부록 실험으로 분리했다
그럼 지도는 왜 만들었나① 커미셔닝 절차 재현(설치 시 SLAM 1회는 실무 표준) ② 경로망(route.yaml) 설계의 근거 ③ SLAM 지도 vs GT 오차 정량화 — V&V 자료
재라우팅은 누가 하나로봇이 아니라 중앙. 추종기는 막히면 정지·보고만 한다(막힘 20s+ 경고) — 로컬 회피를 뺀 것이 Nav2 배제 결정의 핵심
SEC 03 · 코드 워크스루

mapping_sim.py의 여섯 블록, follower.py의 한 루프

mapping_sim.py — T1 뼈대에 추가된 것

순서블록왜 이렇게
1GT 방 구성 (벽 4·박스 3, ROOM v2)좌표를 우리가 아는 방이어야 지도 오차를 정량 비교할 수 있다. box_c는 통로 폭 실측 후 북측 0.4m 이동(삽질 ④)
2체시스 링크 탐색라이다를 붙일 곳. 루트 Xform이 아니라 움직이는 강체여야 한다(삽질 ①) — left_wheel_joint의 Body 관계에서 "wheel"이 없는 쪽을 골라 체시스를 찾는다
3Lidar.create + LaserScan 라이터RTX 라이다(Example_Rotary_2D, 10Hz)를 체시스 하위 높이 0.60m에 생성하고 RtxLidarROS2PublishLaserScan 라이터로 /scan 발행. 메타(스캔 주기·range)는 센서 prim 속성에서 추출
4TF 발행 노드 2개odom→base_link(동적 — 파이썬이 매 프레임 pose를 핀에 기입)와 base_link→lidar_link(고정). SLAM이 요구하는 트리의 하반부
5장애물 큐브 + /obstacle_cmd 구독Twist를 명령 채널로 재활용 — linear.z>0.5면 (x,y)로 순간이동. 높이 1.4m는 라이다 평면 위여야 보이기 때문(삽질 ⑤)
6모드 분기 — --laps(패트롤) / --manual(Twist 추종) / --spawn패트롤은 직진 360스텝@0.6 + 회전 240스텝@π/8 — 저속 회전이 스캔 왜곡 완화의 핵심(삽질 ②). manual 모드가 스테이지 B의 씬이 된다

follower.py — 제어 루프 한 장

매 틱(20Hz, 시뮬 시간 dt):
  ① 도착 판정: 목표 노드까지 dist < 0.35 → 도착 기록, 다음 노드
  ② 안전 필드(히스테리시스):
       front < stop_d(1.2)  → 정지 진입 (횟수 기록, 20s+ 지속 시 "FMS 보고" 경고)
       front > stop_d+0.2   → 재개
       단, 목표 근접(dist<1.2)·정렬 중엔 stop_d를 1.05로 축소 — 코너 노드가 벽에
       가까울 때 필드가 도달을 막는 기하 충돌 방지 (하한은 라이다 블라인드 1.0 바로 위)
  ③ 속도 결정:
       정지 중   → v=0, 단 목표 방향 제자리 회전은 허용 (데드락 방지, 삽질 ⑥)
       |α| > 60° → 정렬: v=0, ω=±0.6
       순항      → v=0.6 (근접 0.2 · 전방 1.5m 내 0.25 감속), ω=2.0·α 클램프
  ④ 명령 램프: v_cmd += clamp(v_des−v_cmd, ±0.5·dt) — T1 실측(물리 즉답형)의 결론
  ⑤ 완주 → 엣지별 (시작·끝·소요) CSV 저장

안전 필드 — 사각 대역의 실제 코드

for r, ang in scan:                     # 전방 ±80° 빔만
    fx = r·cos(ang)                     # 전방 거리
    ly = r·sin(ang)                     # 측면 오프셋
    if 0 < fx and |ly| < 0.45:         # 로봇 반폭 0.33 + 여유 — 진행 대역만
        front = min(front, fx)

원뿔 섹터(각도 ±25°)로 만들면 가까운 측면 물체가 각도 안에 들어와 통로 옆 박스마다 정지한다(삽질 ③). 산업 보호 필드가 로봇 폭 기반 사각인 이유를 실측으로 재확인한 것.

#증상원인해법·교훈
①지도 전체가 회전·오프셋 (평균 269cm)라이다를 articulation 루트 Xform에 부착 — 물리는 링크만 움직여 센서가 스폰 위치에 고정. GT 레이캐스트 잔차 0.2cm로 "원점 고정" 가설 확정센서는 움직이는 링크(체시스) 하위에. 체시스는 바퀴 조인트의 Body 관계로 탐색
②지도가 ~2° 기울고 벽이 번짐 (18cm)π/4 rad/s 회전 중 스캔당 4.5° 스미어 — 10Hz 라이다는 순간 스캔이 아니다매핑 주행은 저속 회전(π/8) — 오차 1/5. 실기에서도 매핑 주행 속도는 별도 관리 대상
③통로 옆 박스마다 오탐 정지보호 필드를 원뿔(각도 섹터)로 구현 — 측면 0.3~0.5m 물체가 각도 안에 든다필드는 로봇 폭 기반 사각 대역(|측면|<0.45m)
