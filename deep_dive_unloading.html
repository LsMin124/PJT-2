SEC 01

하차 작업의 실제 모습

쉽게 말하면 간선 트럭의 짐칸을 열면 상자가 천장 근처까지 낱개로 빽빽하게 쌓여 있습니다(벌크 적재). 작업자는 짐칸 안으로 들어가 위에서부터 상자를 꺼내 컨베이어에 올립니다. 파렛트째 지게차로 내리는 것과는 완전히 다른 작업입니다.

국내 간선 수송은 적재율을 높이기 위해 파렛트 없이 벌크(낱개) 적재가 일반적이다. 그래서 하차는 "파렛트를 내리는 문제"가 아니라 "쌓인 더미에서 낱개를 빼내는 문제"가 된다.

항목내용
작업 환경윙바디·탑차 짐칸 내부. 좁고 어둡고, 여름철 고온. 상자 더미 높이는 사람 키를 넘는다
취급 대상골판지 상자(다양한 크기·무게) + 비닐 파우치 + 마대(자루) + 초대형·초소형 혼재
작업 방식텔레스코픽 컨베이어(짐칸 안까지 늘어나는 컨베이어)를 걸치고, 사람이 상자를 꺼내 올린다
부담 요인허브 가동이 심야에 집중되는 야간 작업, 중량물 반복 취급으로 인한 근골격계 부담, 상시적인 인력 수급 불안정
후속 공정과의 관계하차 속도가 곧 인덕션 라인의 공급 속도 — 하차가 늦으면 뒤 전체가 논다 (연결 분석은 심화 B)
SEC 02

왜 로봇에게 어려운가 — 난점 4분해

"상자를 집어서 옮긴다"는 한 문장이 실제로는 네 종류의 난제로 쪼개진다. 각각이 독립된 연구 분야다.

① 인식 — 어디까지가 한 상자인가

  • 경계 모호 — 골판지 상자끼리는 색·질감이 거의 같다. 빈틈없이 밀착된 더미에서 인스턴스 경계(어디까지가 한 개인가)를 나누는 것 자체가 미지 물체 세그멘테이션 문제다 (방법론은 심화 C · SEC 02)
  • 가림(occlusion) — 앞줄 상자가 뒷줄을 가린다. 보이는 면적이 일부인 상자의 크기·자세를 추정해야 한다
  • 조명 — 짐칸 내부는 어둡고, 입구 쪽은 역광. 비닐 포장은 반사로 깊이 센서(depth) 값이 깨진다
  • 미학습 대상 — 상자 디자인·테이프·라벨은 무한히 다양하다. 특정 SKU를 외우는 방식은 통하지 않고, "처음 보는 물체"를 다루는 모델이 필요하다

② 파지 — 어떻게 집는가

  • 무게·무게중심 미지 — 겉만 보고는 1kg인지 20kg인지 모른다. 흡착 컵 개수·진공 압력·가속도를 보수적으로 잡으면 속도가 떨어지고, 공격적으로 잡으면 낙하·파손이 난다
  • 표면 상태 — 먼지·습기·울퉁불퉁한 테이프 면은 흡착력을 떨어뜨린다. 비닐·마대는 흡착 자체가 어렵다(표면이 변형되며 실링이 깨짐)
  • 그리퍼 선택 — 흡착(진공) 방식이 산업 표준: 윗면·앞면만 접근해도 되고 빠르다. 핑거(집게) 방식은 밀착된 더미에서 넣을 틈이 없어 불리하다

③ 물리 — 더미는 무너진다

  • 지지 관계 — 아래·안쪽 상자를 먼저 빼면 위 더미가 무너진다. "다음에 어떤 상자를 뺄 것인가"는 지지 구조를 고려한 순서 결정 문제다
  • 낙하 대응 — 빼는 순간 주변 상자가 떨어질 수 있다. 사람은 반사적으로 받아내지만, 로봇은 예측·회피·재계획이 필요하다

④ 시스템 — 로봇 한 대의 문제가 아니다

  • 택트 타임 — 후속 컨베이어 속도와 동기화되어야 한다. 한 번 파지 실패로 수 초를 잃으면 라인 전체 처리량이 깎인다
  • 진입 기구 — 짐칸 깊숙이 들어가려면 로봇 자체가 이동 플랫폼 위에 있어야 한다 (상용 제품들이 모두 자주식인 이유)
  • 예외 전달 — 로봇이 못 다루는 물체(마대·파손물)를 사람에게 넘기는 흐름(HITL)이 설계에 포함되어야 한다
SEC 03

상용·실증 로봇 비교

같은 "하차 로봇"이라도 접근 방식이 다르다. 공개된 사양 기준으로 비교한다.

제품/과제방식공개 성능·도입처한계
Stretch
Boston Dynamics		 자주식 이동 베이스 + 팔 + 흡착 컵 어레이. 컨테이너 안으로 진입해 벽면처럼 쌓인 상자를 뜯어낸다 제조사 공개 기준 시간당 수백 개(최대 800개 수준). DHL이 최초 고객으로 대규모 도입 정형 골판지 상자 위주. 마대·비닐 등 비정형 대응은 공개 자료 기준 제한적
Pickle Robot KUKA 산업용 팔 + 머신비전. 트레일러 내부 진입형 크기에 따라 시간당 400~1,500개, 최대 22.6kg. UPS 등 도입 (기사) 역시 상자류 중심. 혼재 화물 비율이 높으면 사람 보조 필요
Dexterity 복수 팔 협조 + 힘 제어 기반 조작. 상차(적재)까지 다루는 것이 특징 FedEx 등과 트럭 적재 자동화 협력 공개 적재 밀도·속도에서 숙련자 수준과의 격차가 관건
국내 국책과제
산업부 로봇산업핵심기술개발		 벌크 하차 자동화 — 박스·비닐 파우치·마대 혼재 화물 인식·피킹. 감압 그리퍼 개발 포함 STC엔지니어링 주관, 성균관대·CJ대한통운 참여 (기사) 연구개발 단계 — 국내 허브의 마대·비닐 혼재 특성을 직접 겨냥한 드문 사례
AI 디팔레타이저

비교에서 읽을 것 모든 상용 제품이 흡착 그리퍼 + 자주식 진입 + 상자류 우선이라는 같은 결론에 도달해 있습니다. 즉 "정형 상자의 벌크 하차"까지는 기술이 수렴했고, 남은 것은 그 바깥 — 마대·비닐·혼재입니다 (SEC 04).
SEC 04

미해결 지점 — 이형물이 진짜 문제다

택배 물량에는 상자가 아닌 것이 상당 비율 섞여 있다. 이형물은 별도 수작업 라인으로 빠지며, 하차 로봇의 성능 수치는 대개 이것을 제외한 값이다.

이형물 유형왜 어려운가연구 관점의 문제 이름
비닐 파우치 형태가 고정되지 않고(집으면 처짐), 표면 반사로 depth 측정이 깨지고, 내용물 쏠림으로 무게중심이 움직인다 변형체(deformable object) 인식·조작 — 강체 가정이 깨지는 영역. 로보틱스에서 활발한 미해결 분야
마대(자루) 여러 소형 물량을 묶은 자루. 무겁고, 형태 불규칙, 흡착 불가 → 사람은 끌어당기거나 안아서 옮긴다 비강체 벌크 파지 — 흡착·핑거 어느 쪽도 정석이 없어 전용 그리퍼(걸이·감압 등) 연구 대상
초대형·장척물 소터 규격 초과. 한 팔 가반하중·리치를 넘는다 양팔 협조 조작 또는 별도 설비 — 자동화 대신 사전 분기(체적 기준 하차대분류)로 우회하는 것이 현재 산업 해법
파손 위험물 외형만으로 취급 주의 여부를 알기 어렵다 취급 등급 추정 — 운송장 정보(품목)와 비전의 결합 문제
  • 현실적 결론 — 산업 현장은 "이형물까지 집는 로봇"보다 "이형물을 초기에 걸러내는 분기"(무게·체적 기반 하차대분류)를 먼저 택했다. 로봇 파지의 대상을 정형 상자로 좁혀주는 시스템 설계다
  • 연구 기회 — 비닐·마대의 인식(변형체 세그멘테이션)과 파지는 공개 데이터도 상용 해법도 빈약하다. 합성 데이터로 접근할 여지가 큰 영역 (심화 C · SEC 06)
SEC 05

시뮬레이션으로 다룰 수 있는 범위

이 문제를 시뮬레이션(Isaac Sim)으로 다룰 때, 잘 되는 부분과 근사에 그치는 부분을 구분해야 한다.

작업시뮬 충실도설명
벌크 더미 생성 (강체 상자)잘 됨다양한 크기의 상자를 물리 낙하(physics drop)로 쌓으면 자연스러운 벌크 적재가 만들어진다 — 인식용 데이터 생성의 핵심
세그멘테이션·자세 라벨 자동 생성잘 됨Replicator의 annotator가 인스턴스 마스크·3D 박스·자세를 자동 출력
흡착 파지근사흡착은 표면 실링 물리를 단순화한 모델(surface gripper류)로 시뮬레이션한다. 성공/실패 경향 검증에는 쓸 수 있으나 절대 성공률은 실물과 다르다
더미 붕괴·지지 관계근사강체 물리로 붕괴 자체는 재현되나, 실제 골판지의 변형·마찰 편차까지는 못 담는다. 파지 순서 알고리즘 비교에는 충분
비닐·마대 (변형체)제한적변형체 시뮬레이션은 비용이 크고 정확도 한계가 뚜렷하다. 인식(외형) 데이터 생성까지가 현실적
권장 실험 설계 ① 상자 크기 분포·적재 높이를 랜덤화한 벌크 씬 수천 개 생성 → ② 세그멘테이션·자세 모델 학습 (심화 C) → ③ "다음에 뺄 상자 선택" 정책(맨 위 우선 vs 지지 관계 고려)을 시뮬 안에서 붕괴 횟수로 비교. 흡착 성공률의 절대값 주장은 피하고, 정책 간 상대 비교로 결론을 낸다.
SEC 06

평가 지표 — 무엇을 재야 하는가

지표정의참고 기준
처리율 (개/시간)시간당 하차 개수. 라인 전체 처리량의 상한을 정한다Pickle 공개치 400~1,500/h가 상용 수준의 감
파지 성공률시도 대비 1회 성공 비율. 실패는 재시도 시간으로 처리율을 깎는다연구 벤치마크는 GraspNet 계열 지표 사용
파손률낙하·압착으로 인한 화물 손상 비율. 상용화의 실질 관문공개 수치 드묾 — 시뮬에서는 낙하 횟수로 대리 측정
개입률 (회/시간)사람이 개입해야 했던 빈도 (막힘·이형물·오류)자동화 시스템의 실효성을 가르는 지표
이형물 처리 범위어떤 유형까지 자동 처리 가능한가 (상자만 / +파우치 / +마대)제품 간 실질 차별화 지점

주의: 벤더 공개 수치는 측정 조건(상자 균일도·혼재율)이 제각각이다. 비교 인용할 때는 반드시 조건을 함께 적을 것.
