SEC 01

파이프라인 개요 — 두 갈래가 있다

쉽게 말하면 로봇이 물체를 집으려면 "어디에 무엇이 있고(인식), 어떻게 집을지(파지 계획), 실제로 집는(실행)" 세 단계를 거칩니다. 이때 물체의 정확한 자세(6D pose)까지 알아내는 경로와, 자세 없이 "집을 지점"만 바로 찾는 경로 두 갈래가 있고, 대상에 따라 골라 씁니다.

인스턴스 세그멘테이션 공통 관문

장면에서 물체 하나하나의 영역(마스크)을 분리한다. 상자 더미·토트 안 혼재물 모두 여기서 시작 — SEC 02.

6D 자세 추정 경로 ① — 모델 기반

물체의 위치 3 + 회전 3 자유도를 추정한다. 형상을 아는 물체(상자·등록 SKU)에 유리하고, 자세를 알면 "어느 면을 어디로" 수준의 정밀 조작이 가능 — SEC 03.

파지점 직접 검출 경로 ② — 모델 프리

자세를 건너뛰고 깊이 영상에서 "집을 수 있는 지점·방향"을 바로 찾는다. 처음 보는 물체·비정형물에 유리 — SEC 04.

실행·복구 공통 마무리

모션 계획으로 충돌 없이 도달하고, 실패하면 재인식·재파지한다. 안 되면 사람에게 넘긴다(HITL) — SEC 05.

적용 구분: 벌크 상자 하차(심화 A)는 "상자"라는 형상 사전지식이 있어 경로 ①이 유리하다. 비닐·마대 같은 이형물과 낱개 투입(심화 B)은 형상을 특정할 수 없어 경로 ②가 현실적이다.

SEC 02

단계 1 — 미지 물체 인스턴스 세그멘테이션

물류 장면의 물체는 대부분 "학습 때 본 적 없는" 것들이다. 그래서 일반 검출기(고정 클래스)가 아니라 미지 물체(unseen object)를 다루는 접근이 필요하다.

접근방법·대표 연구물류 장면에서의 평가
합성 학습 전용 모델 합성 RGB-D로 학습해 실제 장면의 미지 물체를 분리 — UOIS, UCN (NVIDIA) 합성→실사 전이가 검증된 계열. 깊이 정보를 활용해 골판지끼리의 경계도 비교적 잘 분리
파운데이션 모델 SAM(Segment Anything Model) 계열 — 클릭·박스 같은 힌트(프롬프트)를 주면 어떤 영역이든 오려주는 범용 세그멘테이션, 미세조정 없이 사용 가능 범용성은 최고. 다만 "물체 단위"가 아니라 "영역 단위"로 쪼개는 경향(과분할)이 있어 후처리 필요, 추론 비용도 큼
지도학습 미세조정 Mask R-CNN·YOLO-seg류를 합성 데이터로 미세조정 — "상자/파우치/마대" 같은 범주 수준 분류를 함께 얻는다 이형물 분기(심화 A SEC 04)에 필요한 범주 정보를 주는 실용 노선. 합성 데이터 품질이 성능을 좌우 — SEC 06
  • 데이터셋 — 학습: 합성(SEC 06) 위주. 평가: OCID(겹침 장면), ARMBench(실제 물류센터 장면)
  • 지표 — 인스턴스 마스크 mAP(평균 정밀도)와 경계선 정확도 점수인 Boundary F-measure. 파지로 이어지므로 과분할(한 물체를 여러 개로)·미분할(여러 물체를 한 개로) 비율을 따로 보고하는 것이 실용적
  • 난점 대비 — 반사(비닐)로 깊이가 깨지는 픽셀은 마스크 신뢰도에 반영해, 신뢰도 낮은 물체는 파지 후보에서 후순위로 미룬다
SEC 03

단계 2 — 6D 자세 추정 (경로 ①)

쉽게 말하면 "저 상자는 저기에, 15도 기울어서, 이 면이 위로 놓여 있다"를 숫자 6개(위치 xyz + 회전 3축)로 알아내는 문제입니다. 이것을 알면 로봇은 상자의 특정 면을 노려서 집을 수 있습니다.
접근방법·대표 연구물류 장면에서의 평가
학습 기반 (per-object) 물체별로 학습하는 고전 계열 — PoseCNN 등 등록 SKU가 고정된 검수 스테이션에는 유효. 그러나 물체마다 재학습이 필요해 미지 물체가 많은 하차 장면에는 부적합
제로샷 (novel object) CAD 모델(3D 설계 형상) 또는 참조 이미지만 주면 그 물체를 학습한 적 없이 자세를 추정 — FoundationPose (NVIDIA, 합성 대규모 학습) 현재 실용 관점의 유력 노선. 상자는 "가로×세로×높이 파라미터만 다른 직육면체"라 CAD 생성이 쉬워 잘 맞는다
기하 기반 깊이 점군에서 평면·모서리를 찾아 직육면체를 맞추는(fitting) 비학습 접근 상자 한정으로는 강력한 베이스라인. 학습 모델의 성능 주장을 검증하는 비교 대상으로 반드시 포함할 것
  • 벤치마크 — 6D 자세의 표준 평가장은 BOP Benchmark. 데이터 포맷(BOP format)을 따라 두면 자작 합성 데이터도 표준 도구로 평가할 수 있다
  • 지표 — ADD/ADD-S(모델 정점 평균 거리), BOP의 AR(평균 재현율). 대칭 물체(정육면체 상자)는 ADD-S 계열을 써야 회전 대칭이 공정하게 처리된다
  • 실용 절충 — 하차 파지에는 완전한 6D가 필요 없을 때가 많다(윗면의 중심 위치 + 법선, 즉 면에 수직인 방향만 알면 흡착 가능). "필요한 최소 자세 정보"를 먼저 정의하고 방법을 고를 것
SEC 04

단계 3 — 파지 생성 (경로 ② 포함)

그리퍼 종류에 따라 문제와 데이터셋이 갈린다. 물류 하차·투입은 흡착이 주력, 소형 혼재물 피킹은 핑거도 쓴다.

그리퍼방법·데이터셋지표·비고
흡착 (진공) 표면 평탄도·실링 가능성 기반으로 흡착점을 채점 — Dex-Net 3.0(흡착 품질 모델), SuctionNet-1Billion(대규모 흡착 라벨) 흡착점 AP, 실링 성공률. 상자 윗면은 쉽고, 라벨·테이프 요철과 기울어진 면이 실패 요인
핑거 (2지) 점군에서 6-DoF(위치 3 + 방향 3의 6자유도) 파지 자세를 직접 검출 — GraspNet-1Billion(표준 벤치마크), Contact-GraspNet(NVIDIA, 장면 단위 검출) AP(마찰계수별), 실기 성공률. 밀착 더미에서는 넣을 틈이 없어 물류 하차엔 보조적
순서 결정 어떤 물체부터 집을지 — 최상단 우선, 가림 관계 그래프, 더미 안정성 고려 (심화 A SEC 02-③) 시뮬레이션에서 붕괴 횟수·총 소요 시간으로 정책 비교 가능 — 학습 없이도 좋은 연구 지점
SEC 05

단계 4 — 실행과 실패 복구

인식·파지 계산이 성공해도 실제 실행에서는 반드시 실패가 생긴다. 이 절은 실패를 전제로 한 실행 설계다.

  • 모션 계획 — MoveIt2로 파지 자세까지의 충돌 없는 경로를 계획한다. 장면 점군을 충돌 환경(planning scene)으로 갱신하는 주기가 실무 품질을 좌우
  • 파지 검증 — 흡착이면 진공 압력, 핑거면 그리퍼 폭·힘으로 "실제로 잡혔는지"를 확인한다. 잡힌 척 이동하다 낙하하는 것이 최악의 실패
  • 실패 복구 순서 — 재흡착(같은 지점) → 다른 파지점 → 재인식(장면이 변했으므로) → 해당 물체 건너뛰기 → 사람 호출(HITL). 각 단계의 시도 횟수 상한을 정해 무한 재시도를 막는다
  • 사이클 타임 회계 — 인식·계획·이동·파지·이송 각 구간의 시간을 기록한다. 처리율(심화 B의 핵심 변수)은 이 합으로 결정되므로, 어느 구간을 줄일지의 근거가 된다
SEC 06

합성 데이터 설계 — 랜덤화 체크리스트

Replicator로 벌크·혼재 장면 데이터를 만들 때의 설계 항목이다. 원칙: 물리 낙하로 배치를 만들고, 나머지를 도메인 랜덤화로 흔든다.

그림: 실사 데이터를 모으고 라벨을 손으로 붙이는 대신, 시뮬레이터가 장면과 라벨을 함께 만들어낸다. 평가에서 약한 조건이 발견되면 그 조건의 데이터만 골라 다시 생성하는 폐루프가 돈다.

랜덤화 축항목이유
물체상자 치수 분포(소형 90% 반영), 종횡비, 파우치·마대 메시 혼입 비율실제 물량 구성과 맞춰야 평가가 의미를 가짐
배치물리 낙하(physics drop)로 자연 적재 생성 — 적재 높이·밀도·기울기 랜덤손으로 배치한 장면은 실제 더미의 접촉·기울기 통계와 다르다
외관골판지 텍스처·인쇄·테이프·라벨 위치, 오염·손상 데칼(표면에 입히는 이미지 스티커)모델이 "특정 상자 디자인"에 과적합하는 것을 방지
조명·카메라광원 수·색온도·역광, 카메라 자세·초점거리, 깊이 노이즈 주입짐칸 내부의 열악한 조명 조건(심화 A SEC 02-①) 대비
방해 요소배경(짐칸 벽·컨베이어), 무관 물체(distractor) 혼입배경-전경 분리 능력 강화
라벨 출력인스턴스 마스크 + 2D/3D 박스 + 6D 자세 + 가림률 — Replicator annotator(라벨 자동 생성 기능)로 자동 생성. 자세는 BOP 포맷으로 저장한 번의 렌더로 SEC 02·03·04의 학습 데이터를 동시에 확보
  • 규모 가이드 — 세그멘테이션 미세조정은 수천~수만 장 수준에서 시작해 학습 곡선으로 증분을 결정한다. 무작정 수십만 장을 만들지 않는다
  • 검증 세트 분리 — 랜덤화 파라미터가 다른 held-out(학습에 쓰지 않고 떼어둔) 합성 세트 + 소량의 실사(공개셋) 세트를 함께 두어, "합성 안에서만 잘 되는" 과적합을 조기에 잡는다
  • ARMBench의 교훈 — 실제 물류센터 데이터(ARMBench)가 공개돼 있으므로, 합성 학습 모델의 최종 성적표는 반드시 실사 데이터에서 낸다 — SEC 07
SEC 07

평가 전략 — 합성으로 배우고 실사로 증명한다

"어디에서 점수를 재느냐"에 따라 평가의 의미가 달라진다. 세 층위를 구분해 각각 다른 질문에 답하게 한다.

합성 내부 평가 개발 루프

held-out 합성 세트로 mAP·ADD-S를 빠르게 반복 측정. 랜덤화 축별로 성능 민감도를 분석해 어느 축이 중요한지 파악한다.

공개 실사 평가 성적표

세그멘테이션은 OCID·ARMBench, 자세는 BOP 계열, 파지는 GraspNet 지표로. "합성만으로 실사 성능 X%"가 핵심 주장 수치가 된다.

시뮬레이션 폐루프 평가 통합 증명

Isaac Sim 안에서 인식→파지→이송 전체를 돌려 처리율·붕괴 횟수·개입률(심화 A SEC 06 지표)을 측정한다. 심화 B의 DES 모델에 이 사이클 타임을 넣으면 라인 전체 효과로 환산된다.

세 층위의 평가가 각각 다른 질문에 답한다: 내부 평가는 "모델이 배우고 있나", 실사 평가는 "현실에 통하나", 폐루프 평가는 "시스템으로 의미 있나".
