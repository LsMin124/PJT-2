# PJT-2 — AMR 도입 타당성 시뮬레이션 (산타팩토리)

문서 사이트(GitHub Pages)와 참고 자료, SIL 구현 트랙의 저장소.

| 경로 | 내용 |
|---|---|
| `index.html` | 문서 사이트 인덱스 (Pages 엔트리) |
| `pages/plan` `research` `tech` `archive` `working` `product` `ref` | 분류별 문서 페이지 (기획 / 조사 / 기술 / 부록 / 작업 / 제품 / 용어사전) |
| `docs/` | 참고 파일 — 사실 원천(`AMR_프로젝트_전체개괄.md`), 기획 기준선(`AMR_시뮬레이션_기획_보충자료_v2.md`), 기획안·조사 md, PDF·zip(비추적) |
| `sil/` | Isaac Sim · ROS2 구현 트랙 (착수 예정) |

- 새 문서는 해당 분류 폴더에 추가하고 `index.html`에 등록
- 문서 간 사실 충돌 시 `docs/AMR_프로젝트_전체개괄.md`가 우선
