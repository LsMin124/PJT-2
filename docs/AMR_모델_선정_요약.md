# AMR 기준 기종 선정

**결론: 물리 시뮬레이션 기준 기종 = idealworks iw.hub 1종 고정.**
카탈로그 5종(iw.hub · MiR 250 · OTTO 100 · Locus · 나르고)은 견적 비교용 파라미터 프로파일로 유지한다.

## 왜 1종인가

- 물리 검증 공수는 기종 수에 비례 — 8주 일정에서 다기종은 전부 얕아진다
- DES↔물리 오차 보정은 1종에 집중해야 주장 가능한 수준으로 깊어진다
- 견적 스윕은 파라미터로 N종을 커버 — **물리는 좁고 깊게, 견적은 넓고 얕게**

## 선정 논리

| 논리 | 내용 |
|---|---|
| **1. 문제 범위** | 우리 대상은 기존 레이아웃을 유지하는 반송 도입(브라운필드). 시장 1위 Geek+의 GTP 그리드는 레이아웃을 재설계하는 방식이라 후보군에 애초에 없다 |
| **2. 제어 표준** | 뼈대가 VDA 5050 중앙 하달 — idealworks는 BMW 스핀오프로 표준 진영의 핵심이고 iw.hub은 사실상 레퍼런스 구현체. 프로토콜 비공개 기종은 관제 로직을 추측해야 해 검증이 무너진다 |
| **3. 일반화** | 차량 파라미터를 VDA 5050 factsheet 포맷으로 받으면 결과가 특정 기종이 아니라 호환 AMR 일반의 예측이 된다 — MiR 등 파라미터 교체 적용 |
| **4. 자산 신뢰** | Isaac 물리 모델이 BMW–NVIDIA 디지털 트윈 협업 유래의 제조사 공식 에셋 — 후보군 중 유일 |

## 뒷받침 사실

- **실구동 검증 완료(8/24)** — 공식 USD로 창고 씬 주행 성공, 조인트 구조(차동 2륜 + 캐스터 4 + 리프트) 확인. 이미 우리 손에서 굴러간 유일 기종
- 창고 씬·라이다 센서 변형까지 같은 공식 생태계 — 파이프라인 전체를 공식 자산으로 구성
- BMW 물류 현장에서 실운영되는 기종 — "실물 상용 기종을 검증했다"는 발표 서사 성립
- 리프트 기구로 적재·하역 데모까지 확장 가능

## 비교

| | iw.hub | MiR 250 | OTTO 100 | Locus | 나르고 |
|---|---|---|---|---|---|
| 공식 시뮬 모델 | **있음** | 커뮤니티 URDF | 근연 URDF | 없음 | 없음 |
| 실구동 검증 | **완료** | 미실시 | 미실시 | 불가 | 불가 |
| 비고 | BMW 물류 | 글로벌 반송 대표 | 북미 제조 | 3PL 피킹 대표 | 국내 오더피킹 |

실질 후보는 iw.hub vs MiR 2파전 — 제조사 공식 물리 모델과 커뮤니티 URDF 변환 임포트의 차이로 갈린다.

## 반론 처리

| 반론 | 답 |
|---|---|
| 3PL 대표는 Locus 아닌가 | 시뮬 모델 비공개 — 선택이 아니라 가용성 문제. 카탈로그에는 유지 |
| MiR이 더 대중적인데 | 커뮤니티 URDF 변환·튜닝 리스크를 살 이유가 없음. 2차 후보로 유지, iw.hub 보정 완료 후 검토 |
| 반송형이라 피킹 보조와 어긋남 | 어긋나지 않음 — 다중 토트 랙을 리프트로 싣고 피킹 존을 순회하는 투어 미션으로 동일 기종이 피킹 보조를 실물 수행. v1 미션 = 팔레트 반송 + 토트 랙 피킹 투어 2종 |
