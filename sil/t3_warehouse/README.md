# T3 — DXF 공장 씬 (씬 빌더)

"그리드가 곧 씬"이 원칙: 팀원 개편 맵 v5.6(`t3_warehouse_map/map/`)의 occupancy grid와
랙 배치 좌표를 그대로 Isaac USD 씬으로 세운다. DES와 SIL이 단일 소스를 공유하는
구조의 물리 실체.

## 파일

| 파일 | 역할 |
|---|---|
| `build_scene.py` | 씬 빌더 — 그리드→벽·작업대 박스, rack_units→NVIDIA 랙 부품 조립(세로형), omap V&V, 스크린샷 |
| `roof_structure.py` | 박공지붕·상부 철골·H형강 기둥 모듈 (DXF 치수선 실측 기하) |
| `warehouse_scene.usd` | 산출 씬 (재생성물 — untracked) |
| `view_scene.py` | WebRTC 관전 뷰어 (완성 씬 열람용) |
| `http_stream.py` | TCP 전용 HTTP MJPEG 관전 경로 (8211) — 캠퍼스 UDP 차단망 대응 |
| `warehouse_sim.py` | T3 본편 — 씬+iw.hub+물리 라이다, ROS2 개통(/scan /odom /tf /clock, /cmd_vel). iw_hub 콜리전 수술 포함 |
| `ros2/` | localization — AMCL+map_server+foxglove(8765) 런치·파라미터. 오차 0.1~0.4m 개통 검증 |
| `out/scene_*.png` | 검수 스크린샷 (탑뷰·조감·통로 시점) |
| `out/omap_occ.npy` | 씬→점유맵 역생성 결과 (V&V) |

## 실행

```bash
# 선행: sil/t3_warehouse_map/map/ 에서 warehouse_layout_v5_5_final.py 실행 (npy 생성)
cd ~/isaacsim && ./python.sh <repo>/sil/t3_warehouse/build_scene.py
```

## 구성 요소

- **벽·기둥** (그리드 셀값 1): 그리디 메싱으로 병합한 UV 타일링 박스 메시, 높이 9.0m
  (DXF 치수선 실측 — 처마 기둥 상단 +9.000). 릿지 지지 기둥열(y≈57.3)은 십자 심볼
  파편을 투명 콜라이더로 두고(그리드=콜라이더 단일 소스), 비주얼은 columns.npy
  실기둥 중심 12곳에 H형강(플랜지 2+웨브, 상단 +11.0 실측)만 세움
- **박공지붕** (`roof_structure.py`, 설계 실측): i=15%·반스팬 32m → 릿지면 ~+14.5m.
  K1 트러스 15프레임(6m 간격, 상현 15%·하현 9.0→11.0)·퍼린 43·단부 베이 X-브레이싱,
  릿지 환기 모니터 폭 4.5m(루버+엔드캡), 처마 파시아 밴드, 동·서 박공벽 삼각 패널.
  omap 스캔 밴드(z 0.2~1.2) 밖 — V&V 무관. 태양 차단으로 현수등 노출 5.0→5.5 보충
- **컨베이어·작업대** (셀값 5): rect 중심이 컨베이어 라인 밴드 위인지로 구분 —
  컨베이어는 투명 콜라이더 + ConveyorBelt_A08 비주얼(L자 연결 포함 6기),
  작업대도 투명 콜라이더(0.9m, 라이다 평면 위 유지) + `packing_table` 에셋 16기
  (그리디 분할 병합을 위해 연결 성분 중심 배치, 동봉 컨테이너 리지드바디 비활성)
- **현장 드레싱**: 인바운드 파렛트 밴드에 지게차 1대(정적 콜라이더 — 셀값 6 rect
  안 주차 포켓), 사무실은 파티션·모니터·키보드·PC·파일캐비닛 뱅크+프린터·
  마커보드·책장·소화전함 등 가구 186점(문 개구부 회피 좌표, V&V 사무실 마스크 제외)
- **랙** (rack_units — 세로형 더블로우, v6.0 구역제): 유닛 3.0m — 통로 반쪽당 3랙,
  구역(A~V 22개) = 통로 반쪽 + 마주보는 행 3칸×2 = 6랙(zones.json). `SM_RackFrame_03`
  유닛 경계 공유 n+1개 + `SM_RackShelf_01`(베이 4.0m → 장축 0.75 스케일 정합) 유닛당
  2데크(+바닥 = 3단). 컴포즈된 부품은 가로 정렬이므로 **z축 90° 회전 조립**
- **철제 창고 외피** (설계도 판독 반영): 외벽 샌드위치 패널(단색 OmniPBR+패널
  노멀), 기둥·윈드 컬럼·월 거트는 랙 프레임과 동일한 MI_FrameA_01(아연도금 스틸),
  바닥 MI_Floor_02b(콘크리트). 윈드 컬럼은 6m 프레임 축, 거트 3단 — 시각 전용
- **화물 드레싱** (운영 모델): 바닥 파렛트 밴드(셀값 6)는 rect에서 래핑 재고 더미를
  자동 생성(교차 적재 최대 4단 ~2.0m + 반투명 랩, 4단 55%·3단 35%·2단 10%, 빈 자리
  3%, 179개), 랙은 피킹 스테이지 — 낱박스 1,923점(슬롯별 채움 45~90% 편차·소적재·
  뒷줄, 빔 2단 1.35/2.7로 층간 여유 0.97m → 관통 0). 결정적 의사난수 배치,
  USD 인스턴싱. 콜라이더는 그리드 rect 그대로(단일 소스)
- **충전 스테이션 6기** (stations.json charger): 도킹 셀(x 107.8)은 자유 공간이라
  실물 캐비닛은 동벽 실내면(x 109.90, 벽 팽창역 안)에 벽걸이 — LED·케이블 트레이·
  베이 도장 포함, 전부 collide=False (스캔 밴드와 겹치는 높이 — 콜라이더 켜면 오검출)
- **도어 4개소** (서·동 박공벽, y 38.3~44.6 / 70.3~76.7): 그리드의 문 구간은 값4
  스트립 양옆 전고 벽 라미나로 봉인 상태(USD bbox 스캔 실측) → 씬도 **폐쇄 셔터**로
  표현(안팎 리브 패널+하우징+잼 포스트+상부 메꿈). 그리드=콜라이더와 정확히 일치
- **스테이션 앵커 46개**: stations.json 전 지점 = `/World/anchors/<type>_<i>` Xform —
  이후 프로젝트가 좌표를 씬에서 직접 질의하는 표준 통로
- 설계도의 메자닌(+4.5m)은 **범위 외 확정** — 지지 기둥이 2D 그리드를 바꾸므로 미구현
- **V&V**: `isaacsim.asset.gen.omap`으로 씬→점유맵을 역생성해 원 그리드와 diff —
  "씬이 그리드와 일치한다"를 자동 검증. 현행 결과: 벽·컨베이어·작업대·파렛트
  재현율 100.0%, 랙 풋프린트 점유 93.3%(빔 2단 전환에 따른 기대 변화),
  풋프린트 밖 오검출 0셀
