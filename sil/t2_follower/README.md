# T2 스테이지 B — 자체 추종기 (로봇 레벨 실행기 초판)

확정 아키텍처의 로봇 실행기: 경로망 노드 시퀀스를 순회하는 ROS2 노드.
Pure Pursuit 방위 제어 + **가속 램프**(T1 환류) + **사각 보호 필드**(정지·재개) + 엣지 통과시간 실측(DES 환류).

## 파일

| 파일 | 역할 |
|---|---|
| `follower.py` | 추종기 노드(rclpy, 시스템 Humble) — /odom·/scan 구독, /cmd_vel 발행 |
| `route.yaml` | 경로망(노드·투어) + 설계 규칙 3 |
| `out/edge_times_baseline.csv` | 기준선 4바퀴 20엣지 실측 |
| `out/edge_times_obstacle_lap.csv` | 장애물 투척 랩 실측 |

## 실행 (검증된 절차, 2026-08-27)

```bash
# 1) 씬 (t2_mapping 재사용, 수동 모드 + 경로 시작점 스폰)
source /opt/ros/humble/setup.bash
cd ~/isaacsim && ./python.sh <repo>/sil/t2_mapping/mapping_sim.py --manual --spawn -4.5 0

# 2) 추종기 (ready 후)
python3 <repo>/sil/t2_follower/follower.py --laps 4 --label baseline

# 3) 장애물 투척/제거 (별도 셸 — linear.z>0.5일 때 x,y로 순간이동)
ros2 topic pub -1 /obstacle_cmd geometry_msgs/msg/Twist '{linear: {x: 0.5, y: 3.6, z: 1.0}}'
ros2 topic pub -1 /obstacle_cmd geometry_msgs/msg/Twist '{linear: {x: 20.0, y: 20.0, z: 1.0}}'
```

## 기준선 엣지 통과시간 분포 (DES 환류)

| 엣지 | 길이 | 평균 | 표준편차 |
|---|---|---|---|
| n1→n2 | 3.6m | 12.77s | 1.31 (초기 상태 변동) |
| n2→n3 | 9.0m | 29.23s | **0.17** |
| n3→n4 | 7.1m | 23.74s | **0.06** |
| n4→n5 | 9.0m | 28.60s | **0.03** |
| n5→n1 | 3.5m | 14.30s | **0.01** |

**핵심 발견**: 엣지 통과시간은 사실상 **결정적**(±0.2s 미만)이다. 분산의 원천은
① 초기 상태 ② **정지 이벤트**뿐 — 장애물 1회 정지 페널티 실측 **+7.6s**(n2→n3 36.9s vs 29.2s).
→ DES 엣지 모델 = 결정적 기본 시간 + 정지 이벤트 페널티 분포. 기획 기준선(§3 DES 모델링 요소)의
"엣지 통과시간 분포 + 통로 점유 외란" 구조가 실측으로 지지된다.

## 설계 교훈 (실측으로 확정 — 전부 삽질에서 나옴)

1. **보호 필드는 원뿔이 아니라 사각** — 전방 원뿔 섹터는 통로 옆 박스(측면 0.5m)에 오탐. 로봇 폭 기반 진행 대역(|측면|<0.45m)으로 교체
2. **통로 최소 폭 ≈ 1.5m** — 로봇 폭 0.66 + 양측 필드 여유 + 라이다 블라인드(range_min 1.0m) 마진. 1.1m 회랑은 통행 불가 실측 판정 → ROOM v2(box_c 이동)
3. **코너 노드는 진행방향 벽에서 ≥1.4m** (도착 반경 0.35 + 근접 필드 1.05) — 근접·회전 중에는 필드 축소(속도 연동 필드, 하한은 라이다 블라인드 위)
4. **정지 중 제자리 회전 허용** — 아니면 정면 장애물에 영구 데드락. 막힘 20s+는 경고만: 재라우팅은 중앙(FMS) 몫(아키텍처 원칙)
5. **장애물은 라이다 평면보다 높아야 보인다** — 0.6m 큐브는 라이다(~0.7m) 빔이 위로 지나가 불가시 → 로봇이 밀고 들어감(실측). 테스트 장애물 1.4m로 수정
6. 접근 구간이 장애물 모서리를 스치지 않게 **투어는 최근접 노드부터 회전 시작**
