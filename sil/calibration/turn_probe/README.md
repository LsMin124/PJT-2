# calibration/turn_probe — iw.hub 스팟턴 실측 (FMS 헤딩 모델 상수)

FMS 파트가 기다리는 두 상수(기준선 v3 §5.2·§9)를 Isaac 물리로 잰다.

| 상수 | 뜻 | 얻는 방법 |
|---|---|---|
| 앞축 종방향 위치 | 회전 중심(구동축)이 차체 어디에 있나 → 뒤 칸 점유(`REAR_CELLS`)·스윙 반경 | USD 링크 오프셋 + 차체 bbox (`wsim_wrap.py`), 회전 중 오돔 원점의 원 궤적 반경 (`spin_probe.py`) |
| 회전 각속도 | 지령 대비 실제 요 각속도, 상승·정지 시간, 90° 회전 소요(`TURN_TICKS`) | `/cmd_vel` 각속도 스텝 5종 + T4 TurnController 폐루프 90° ×4 (`spin_probe.py`) |

## 파일

| 파일 | 역할 |
|---|---|
| `wsim_wrap.py` | T3 `warehouse_sim.py`를 무수정으로 띄우고 ready 직후 iw_hub 링크 오프셋·bbox(루트 기준)를 출력 |
| `spin_probe.py` | Humble 쪽 프로브 — 각속도 스텝(0.3·0.6·0.9·1.2·1.5 rad/s, 6 s 유지 + 4 s 정지) → 요 응답·원 궤적·관성 분석, 이어서 TurnController 90° 회전 4회 |
| `run_spin.sh` | 위 둘을 순서대로 실행하고 Isaac을 내린다. `./run_spin.sh <label>` |
| `out/spin_<label>.csv` `.json` | 원자료(t x y yaw wz cmd_w phase)와 요약 |
| `out/isaac_<label>.log` | Isaac 로그(`[wrap]` 줄이 정적 오프셋) |

## 실행

```bash
cd sil/calibration/turn_probe && ./run_spin.sh run1     # Isaac 인스턴스 0개인 상태에서, 약 2분
```

분석 정의: 정상 각속도 = 스텝 마지막 3 s(시뮬 시간) `/odom` 각속도 중앙값. 상승 시간 = 정상값의 90% 도달까지.
회전 중심 = 정상 구간 오돔 (x,y)의 최소제곱 원 맞춤 — 반경 R이 0이면 오돔 원점(=루트 프림)이 곧 회전 중심.
종·횡 오프셋은 스텝 시작 헤딩 기준(+앞, +좌). 관성 각 = 지령 0 이후 정지까지 더 돈 각.

FMS 인도 상수:
- **회전 중심 = 구동축 = 포즈 원점.** 회전 중 원점 이탈 ≤ 1.3 cm이므로 "바퀴 축심을 회전 중심으로 하는 스팟턴"이 이미 성립한다.
- **뒤 칸 점유 1**: 앞 0.40 m < 0.5 m(자기 칸 안), 뒤 1.03 m < 1.5 m(뒤 칸 안). 스윙 반경 1.09 m는 주변 8칸(3×3)에 걸치므로 회전 틱의 스윙 예약은 3×3 블록.
- **90° 회전 1.9 s**(정착 포함 2.5 s) → 1 s 틱 기준 회전 2틱. 참고: 1 m 직진 2.2 s(T4 E2E).
- 개루프 정지 관성이 1.2 rad/s에서 14°이므로 회전은 반드시 폐루프(현 T4 구조)로 끝내야 한다.
- 개선 1건: 4회차 −4.9°는 done 판정 뒤 관성으로 더 돈 것. TurnController.done 조건에 각속도(|wz| < 0.05 rad/s) 정지를 추가할 것.
